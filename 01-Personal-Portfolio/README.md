# Sancia | Developer Portfolio 👩🏻‍💻

A responsive personal developer portfolio built using HTML5 and CSS3.

## 🌐 About the Project

This portfolio introduces me as an aspiring software developer and Computer Science Engineering student. It highlights my interests, technical skills, projects, and contact information.

## ✨ Features

- Modern dark-themed design
- Responsive layout for mobile and desktop
- Navigation bar with smooth scrolling
- About Me section
- Technical Skills showcase
- Projects section
- Contact section

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries

## 📂 Project Structure

```text
Personal-Portfolio/
└── index.html
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
