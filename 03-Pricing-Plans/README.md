# Pricing Plans Website 💳

A responsive pricing plans website built using HTML, CSS, and JavaScript. It allows users to compare different subscription plans and switch between monthly and yearly pricing.

## ✨ Features

- Three pricing plans: Basic, Pro, and Premium
- Monthly and Yearly pricing toggle
- Dynamic price updates using JavaScript
- Active button highlighting
- Hover animations on pricing cards
- Responsive design for mobile and desktop screens

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- JavaScript
- DOM Manipulation

## 💰 Pricing Plans

| Plan | Monthly | Yearly |
|---|---:|---:|
| Basic | ₹0 | ₹0 |
| Pro | ₹499 | ₹399 |
| Premium | ₹999 | ₹799 |

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `03-Pricing-Plans` folder.
3. Open `index.html` in your web browser.
4. Switch between Monthly and Yearly to view the different prices.
