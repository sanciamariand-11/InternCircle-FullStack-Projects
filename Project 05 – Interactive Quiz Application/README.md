# Interactive Quiz Application 🧠

An interactive and responsive quiz application built using HTML, CSS, and JavaScript. It allows users to test their web development knowledge through multiple-choice questions and view their final score.

## ✨ Features

- Multiple-choice quiz questions
- Five web development questions
- Instant answer validation
- Highlights correct and incorrect answers
- Progress bar to track quiz completion
- Automatic score calculation
- Final score display
- Restart quiz option
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Handling

## 🎯 Topics Covered

- HTML fundamentals
- CSS basics
- Hyperlinks and HTML tags
- JavaScript JSON methods
- Browser Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `05-Interactive-Quiz` folder.
3. Open `index.html` in your web browser.
4. Select an answer for each question.
5. Click Next Question to continue.
6. View your final score and try again!
