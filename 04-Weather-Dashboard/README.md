# Weather Dashboard 🌦️

A responsive weather dashboard built using HTML, CSS, and JavaScript. It allows users to search for any city and view its current weather conditions along with a five-day forecast.

## ✨ Features

- Search weather by city name
- Display current temperature
- Show weather conditions with icons
- Display feels-like temperature
- Show humidity and wind speed
- Five-day weather forecast
- Loading and error messages
- Responsive design for mobile and desktop screens
- Automatically loads weather information for Salem

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- Open-Meteo Geocoding API
- Open-Meteo Weather API

## 🌐 API Used

- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)
- [Open-Meteo Weather API](https://open-meteo.com/en/docs)

**Note:** No API key is required. An active internet connection is needed to retrieve weather information.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `04-Weather-Dashboard` folder.
3. Open `index.html` in your web browser.
4. Enter a city name in the search box.
5. Click Search to view the latest weather information.
